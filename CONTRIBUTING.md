# Contributing to Dishcovery

## Team Workflow

1. Pull the latest `main` branch.
2. Create a branch for your assigned task.
3. Make and test your changes.
4. Commit with a clear message.
5. Push your branch to GitHub.
6. Open a pull request and link the relevant issue.
7. Request a review from at least one teammate.
8. Merge only after review and testing.

## Branch Names

Use descriptive branch names:

- `feature-meal-api`
- `feature-cli-demo`
- `feature-streamlit-app`
- `feature-recipe-utils`
- `fix-empty-results`
- `docs-readme`

## Team Rules

- Do not push feature work directly to `main`.
- Do not commit `.env`, `.venv`, API keys, or other secrets.
- Keep each pull request focused on one task.
- Pull the latest `main` before beginning new work.
- Explain how you tested your work in the pull request.
- Each member must make at least one visible commit and one pull request.
